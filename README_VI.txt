CUSTOM TC - TELEGRAM BOT FREE FIRE
==================================

THUONG HIEU
- Ten: CUSTOM TC
- Slogan: CUSTOMTC
- Server hien thi: VIETNAM (VN)

CHUC NANG DA CO TRONG SOURCE
- /start: mo menu
- /register: dang ky UID va chon 1 trong 8 khung gio
- /uid: nhap/cap nhat UID
- /schedule: xem khung gio
- /rank: xem danh sach dang ky trong chat hien tai
- /profile: xem dang ky cua minh
- /board: tao anh PNG bang dang ky
- /cancel: huy thao tac

Du lieu duoc luu bang SQLite. Dang ky trong nhom va chat rieng duoc tach rieng.
Moi tai khoan co mot dang ky trong moi chat; dang ky lai se cap nhat UID/khung gio.

QUAN TRONG - GIOI HAN
- Source nay KHONG tu lay duoc lich su tran Free Fire.
- Telegram Bot API khong cung cap du lieu tran dau Free Fire.
- Muon co kills/wins/lich su tran tu dong can mot API nha cung cap hop le, co tai lieu va quyen truy cap.
- /rank va /board hien tai la DANH SACH DANG KY, khong phai bang xep hang kills/wins.
- Server VN la nhan hien thi. Ma vung API (neu nha cung cap yeu cau) phai xac minh rieng.

CAI DAT TREN MAY CHU PYTHON
1. Cai Python 3.10 tro len.
2. Giai nen ZIP.
3. Tao file .env bang cach copy .env.example thanh .env.
4. Mo .env, thay BOT_TOKEN bang token tu @BotFather.
5. Cai thu vien:
   pip install -r requirements.txt
6. Chay:
   python run.py

BAO MAT
- Khong gui token cho nguoi khac.
- Khong dua token vao anh chup man hinh, nhom chat, GitHub cong khai.
- Neu lo token, vao @BotFather > /revoke de thu hoi va tao token moi.
- Khong bao gio gui mat khau Free Fire cho bot.

CHAY TRONG NHOM
- Them @CUSTOMTC_VN_bot vao nhom.

- Neu nhom co nhieu bot, co the go lenh kem username: /register@CUSTOMTC_VN_bot
